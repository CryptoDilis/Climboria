# Public historical evidence boundary — review only
2026-11-28 UTC. Local authorization reconciliation is not a public-chain indexer or a release gate. The offline comparator intentionally only accepts two matching, stable observations for the exact same reported finalized head, parent and anchor. This is strict and may reject healthy providers that have different finalized heights. Never infer cryptographic finality, ancestry, transaction inclusion, independent infrastructure or authentic state from matching RPC JSON. The narrow single-transaction case does not establish public Base pre-state: L2 system transitions, protocol upgrades and execution context must be independently reproduced. General multi-transaction blocks require exact transaction-index execution from authenticated state and verified block inputs; parent-block eth_call alone is insufficient. Do not silently substitute latest state. Future production trust roots must be independently approved exact runtime/deployment manifest, chain protocol and finalized L1/L2 evidence, verified ancestry/inclusion and state, replay or authenticated execution evidence, durable canonical/idempotent records and explicit reorg handling. The comparator makes no network calls, no signatures or transactions; all successful outputs remain NO_GO. Proposed expense lifecycle rules remain undecided.
