# Offline token accounting
Synthetic BigInt models only; no contracts, network, real evidence, wallet, persistence or production integration. The fixture marker is deliberately not a proof. The fee model assumes final net collected CLIMB fees (after any refunds); it does not verify payment or custody. Illustrative 10% burn / 5% game share applies to cumulative fees, not trade volume; actual percentages await approval. Rounding remainder remains in other allocation; actual custody and treasury/game distributions are not modeled. Migration assumes permanent original burns only, no lock or replacement scenario; destination checks are format only, not ownership. The cap is hypothetical and counts lifetime issuance, not current supply. Pending claims can settle before irreversible model closure; economic burns never restore capacity. A production system needs verified holder entitlements, canonical unique proof identifiers, exact source instruction/finality, destination signatures, durable state and recovery, authorization, independent security review and onchain balance/receipt reconciliation. No live release.
