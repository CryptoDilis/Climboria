# Read-only candidate probe (not holder certification)
Uses existing two privately configured HTTPS Solana RPC endpoints and genesis reference. Discovers at most 20 largest token accounts per provider, then reads the union plus mint in one finalized getMultipleAccounts call per provider. Reports parsed token authority, amount, state and candidate sum vs mint supply; no wallet, signing, transfer or burn. The same-slot flags and matching parsed digest do not establish raw data accuracy, independent provider ownership, canonical blockhash, historical snapshot completeness, beneficial ownership or curve custody. Largest-account discovery can be incomplete; a full reported sum is still not independently certified. Strict parsed mint metadata and account extension checks reject unsupported responses. Public artifact includes only public chain account fields and sanitized diagnostics. No URL/secret output. Manual main-only workflow uses existing RPC secret configuration; no RPC request in PR or push jobs. Do not use this as claim eligibility or authorization.
