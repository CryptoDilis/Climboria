# Testnet operator handoff — CLIMB bridge

**No mainnet deployment. No private keys in GitHub, chat or CI.** Only public addresses are needed for the next read-only step.

## Step 1 — separate testnet wallets
Create fresh test-only wallets for Solana Devnet and Base Sepolia, with no real assets. Keep seed phrases and private keys offline with the owner. Obtain test SOL and Sepolia ETH using reputable faucets listed by the respective networks. Faucet availability and eligibility are not verified here. No purchase of real SOL/ETH is required for the testnet itself. Send only the two public receiving addresses for the balance check.

## Step 2 — payer evidence
Preferred: [CLIMB Testnet Payer Preflight](https://github.com/CryptoDilis/Climboria/actions/workflows/climb-testnet-payer-preflight.yml) → Run workflow → main → enter the two **public receiving addresses** → Run workflow. Available on main. Inputs and logs are repository-visible, so use only dedicated testnet public addresses. No private key, seed phrase, RPC key, signing or transaction. Inspect the job summary for balances; NO_GO remains until the other deployment gates are satisfied.

Alternatively, from the repository root with Node 22, run the following with actual public addresses substituted:
```sh
node token/climb-bridge/testnet-payer-preflight.mjs SOLANA_PUBLIC_ADDRESS BASE_PUBLIC_ADDRESS
```
This reads only public Devnet and Base Sepolia RPCs, verifies network IDs, checks finalized balances and estimates current mint plus one ATA rent and sample NTT program storage; reports combined storage shortfall on main. It refuses the real CLIMB mint as a payer. A nonzero balance does not establish ownership, complete funding or deployment readiness. Do not transfer to an address generated by this tool (it generates none).

## Step 3 — staged creation after review
- Solana: follow [the distinct test mint plan](testnet-solana/README.md). Verify the installed CLI against pinned [official option definitions](https://github.com/solana-program/token-2022/blob/e8ca680ca8aeb12f9598524b003c776c6a4168f2/clients/cli/src/clap_app.rs). Use an explicit separate Devnet config, verify genesis and signer public key each time; Token-2022 program ID, six decimals, metadata pointer enabled, no freeze flag. Initialize exact test metadata, create holder ATA, mint 1,000 test units; independently inspect supply and metadata before disabling authorities. Never apply authority revocations to an existing mainnet token.
- Base: build the [tested Sepolia-only contract](testnet-base/README.md) using pinned compiler/dependency; estimate deployment gas for reviewed creation bytecode with the public testnet payer address. Verify chain 84532, initial zero supply, six decimals and owner-controlled binder before any manager binding. No production token creation.
- NTT: do not bind an arbitrary contract or deploy using unverified binary. Check source release, build output, exact audit scope, roles, governance, cost and peer identities first. Estimate Solana program rent and Base transaction gas from actual artifacts. No simulation bypass. Sign only reviewed testnet transactions in local owner-controlled environment.
- Record finalized transaction hashes and test addresses in the development record; then run both transfer directions with small test amounts, reconcile escrow and outstanding supply, negative tests and review. Testnet success does not itself authorize mainnet.
