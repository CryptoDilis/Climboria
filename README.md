# Climboria

Climboria is being developed as a browser-first multiplayer mountain survival and exploration game, alongside planned Launchpad and DEX products.

## Current direction
- Game first: expeditions, survival, equipment, crafting, exploration, and cooperative play.
- The old pot-climbing concept and legacy leaderboard/season-ranking system are retired from the current direction.
- No badge system, fixed summit reward treasury, or guaranteed player token payout is currently committed.
- Launchpad and DEX are planned products; fees, taxes, tokenomics, and launch timing are not finalized.
- Platform revenue, if earned after launch, is separate from any future player incentive budget. Any incentive must be funded, sustainable, and publicly documented before announcement.
- Token launch and on-chain game features are not live unless officially announced and implemented.

## Status
This repository contains the Climboria website and project documentation. Product descriptions are plans, not proof that gameplay, wallets, token creation, swaps, NFTs, or rewards are operational.

## Safety and transparency
Do not treat proposed token details, reward concepts, or mockup interfaces as live financial products. Any smart contracts, token launch, transaction fees, and asset-handling features require implementation, testing, and independent security review.
