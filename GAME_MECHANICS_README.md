# Climboria — Game Mechanics README

**Status:** Design draft (v0.1)  
**Purpose:** A living reference for agreed game rules. Update this document as mechanics are added, changed, or removed. These rules are design decisions; they are not yet implemented unless separately confirmed in the game.

## 1. Regular Expeditions (Mountains 1–10): Death and Respawn

- The **first death/respawn has no penalty**.
- After the first death, subsequent deaths progressively cause random items to fall out of the player's Bag.
- Respawn at the player's last checkpoint.
- The exact progression/rate of item loss and any cap still need to be decided.

## 2. Jarrell's Peak: High-Risk Death Rules

When a player dies on Jarrell's Peak:

1. The player automatically returns to the **Starting Point**.
2. A **random item** drops from the player's Bag at the death location.
3. Other climbers who pass by can pick up the dropped item.
4. The dropped item has a **90-second decay timer**. If it is not recovered before the timer expires, it disappears.
5. Jarrell's Peak is intentionally dangerous: death can cost carried loot, and recovery is a race.

## 3. Death Stones (Jarrell's Peak)

There are two Death Stone types. Each stone is **single-use** and can teleport its user(s) back to the death location.

### Solo Death Stone
- Teleports the individual user to their own death spot.
- One use.

### Party Death Stone
- Teleports **every member of the party**, regardless of where each member is on the map, to the **exact death spot** of the party member whose death is being recovered.
- One use.
- The destination is the exact death spot—not a nearby safe landing point. Any hazards at that location are part of Jarrell's Peak's risk.

Death Stones are intended to let players quickly return and try to recover dropped loot or continue their climb.

## 4. Open Design Questions

- For regular Expeditions 1–10, how many random Bag items drop on each death after the first, and is there a maximum?
- How are Death Stones acquired/priced, and can a party activate its Party Death Stone if some members are offline or unable to participate?
- What happens if a player or party teleports to a death spot that is occupied or immediately lethal? Current agreed rule: teleport to the exact spot; no safety offset has been specified.
