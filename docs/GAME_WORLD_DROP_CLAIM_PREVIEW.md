# Isolated world-drop claim prototype

2026-11-26 PHT — proposed, not deployed. This server-only module models one fixed synthetic nonfinancial drop in a separate fixture room, no inventory mutation or production import. A serialized trusted caller supplies current authenticated actor identity, health, authoritative position and obstruction result. Claim uses a transactional durable receipt; competing requests cannot both win. It never grants an item. The fixed drop is not replenished. No account, paid, wallet or on-chain asset can be supplied. Tests cover concurrent claim, stale/invalid actor, blocked/out-of-range target, storage failure and ambiguous commit, durable replay, corrupt record and production room refusal. CI pending.
