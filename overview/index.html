OFFICIAL PROJECT OVERVIEW

One climb.
Room to grow.

Climboria is building a browser-based climbing game focused on skill, progression, and community. The goal is to make the game enjoyable first, then introduce optional ecosystem features carefully as they become ready.

What we're building

Game first. Speculation later.

⛰️

Browser climbing game

A climbing experience designed to run in a web browser, with mobile and desktop play in mind—no game download intended.

CORE EXPERIENCE
🧗

Skill and progression

Climb through increasingly challenging routes, learn the controls, and build toward a broader level-based experience.

EXPANDING
🏆

Community competition

Leaderboards, events, streaks, and community rewards are part of the direction; features will be labeled clearly until connected and verified.

PLANNED FEATURES

The ecosystem direction

Optional features—not prerequisites to play.

🎮

Play without crypto

The game should remain accessible to players who simply want to climb. Wallets and tokens should not be required for the core game.

↔️

Swap and marketplace

A branded swap experience and future marketplace may be added separately after integrations, safety checks, and availability are verified.

IN DEVELOPMENT / PLANNED
🌐

Solana first, Base later

The intended blockchain sequence is to evaluate Solana first, with Base considered later. Cross-chain features are not promised until they are built and tested.

FUTURE DIRECTION

Development roadmap

Milestones may change as testing reveals what needs attention.

01

Stabilize the core game

Prioritize reliable gameplay, controls, camera behavior, and a usable mobile experience.

02

Build level progression

Improve level selection and structure levels so future additions can be made without rebuilding the whole site.

03

Connect community systems

Validate leaderboards, events, and reward tracking before presenting them as live features.

04

Integrate Web3 carefully

Test wallet and swap integrations, publish verified official details, and evaluate Base only when the project is ready.
